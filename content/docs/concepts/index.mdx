Concepts is the map of the factory: five ideas, each of which the rest of the
docs assume.

- **[The factory model](/docs/concepts/the-factory-model)** — what it means to
  treat software creation as a production line rather than a session.
- **[Worker containers](/docs/concepts/worker-containers)** — the fresh,
  disposable environment every round builds in, with no host path and no
  published port.
- **[Orchestration](/docs/concepts/orchestration)** — a deterministic state
  machine, and OpenCode as the coding agent inside the container.
- **[The Kanban and the human feedback loop](/docs/concepts/kanban-and-the-human-feedback-loop)** —
  five swimlanes, three decisions, three rounds, and what happens on exhaustion.
- **[Multi-project processing](/docs/concepts/multi-project-processing)** — many
  repositories, one factory, round-robin order.

Each page states what the idea is, why the design chose it, and what it costs.
Read them in order if you are new to the factory; jump straight to
[Architecture](/docs/architecture) if you would rather see how they compose.
