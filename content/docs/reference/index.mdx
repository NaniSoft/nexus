Reference is for looking things up rather than reading through.

- **[Configuration schema](/docs/reference/configuration-schema)** — every
  field the design's configuration model carries, its type, and whether it is
  required. Documented as a **design-stage model**, not a runnable reference.
- **[Glossary](/docs/reference/glossary)** — the factory's vocabulary, defined
  once so the rest of the docs can use it without re-explaining.

Where a field's name or type is not yet fixed by the design, the schema says so
instead of guessing. Nexus has not shipped, and a reference that pretended
otherwise would be the least useful page on this site.
