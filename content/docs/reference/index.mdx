Reference is for looking things up rather than reading through.

- **[Configuration schema](/docs/reference/configuration-schema)** — every field
  a project file carries, its type, and whether it is required. **Fixed, not
  illustrative:** these are the names the loader reads.
- **[Glossary](/docs/reference/glossary)** — the factory's vocabulary, defined
  once so the rest of the docs can use it without re-explaining.

Where a field's type or permitted value matters and is not in the schema page,
the schema says so rather than guessing. There is still no released version, so
nothing here promises compatibility across releases — but a reader can write a
valid file today, and that is the difference between a reference and a
description of one.
