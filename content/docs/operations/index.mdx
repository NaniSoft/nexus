Operations covers the two things a factory has to get right to be worth
running: standing it up, and knowing its output is good.

- **[Deployment](/docs/operations/deployment)** — Docker Compose, one
  deployment serving every configured project, and the environment the
  factory's secrets live in.
- **[Testing strategy](/docs/operations/testing-strategy)** — unit,
  Testcontainers integration, end-to-end, and chaos: four layers, each answering
  a question the layer below cannot.

Both pages describe the design. The factory has not shipped, so there is no
runbook here and no upgrade path — that is deliberate, and
[the status note](/docs/introduction#status) explains what the docs are instead.
