Operations covers the two things a factory has to get right to be worth
running: standing it up, and knowing its output is good.

- **[Deployment](/docs/operations/deployment)** — Docker Compose, one
  deployment serving every configured project, the machine-only limit, and the
  daemon deviation named in the file.
- **[Testing strategy](/docs/operations/testing-strategy)** — one application
  seam for policy, real adapters beneath it, and the requirements of a service
  reproduced rather than recorded.

The testing page is the more important of the two to read skeptically. It names
what the suite cannot reach as well as what it can, because a strategy that only
lists its strengths is a strategy nobody can rely on.

There is no runbook and no upgrade path yet, because there is no release to
upgrade from. That is deliberate, and
[the status note](/docs/introduction#status) says what the docs are instead.
